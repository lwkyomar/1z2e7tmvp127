# Family GPS Offline Tracker (Android)

## Инструкция по сборке APK:
1. Загрузите все эти файлы в ваш репозиторий GitHub.
2. Файл .github/workflows/build-apk.yml автоматически запустит GitHub Actions и соберет APK в облаке!
3. Либо откройте эту папку в Android Studio и нажмите:
   Build -> Build Bundle(s) / APK(s) -> Build APK(s)
